# Sri-Vadiraja-Teertha-Sode-Mutt
This project is a humble digital initiative to connect devotees with Sri Vadiraja Teertha Sode Mutt. The app provides easy access to Mutt history, seva booking, and important updates in a clean and user‑friendly way. Built with dedication using React Native and Firebase for the Vaibhavotsava Hackathon.
